1. Speed at Lowest Point ($v_{\text{bottom}}$)

ET1 = ET(bottom)
mgh1 + 0 = mghbottom + ½mvbottom²
vbottom = √[ 2g(h1 − hbottom) ]

v = √[ 2(9.81)(0.75 − 0.20) ] = 3.28 m/s
2. Max Height on Other Side ($h_2$)

ET1 = ET2 (where v2 = 0 m/s)
mgh1 + 0 = mgh2 + 0
h2 = h1 (independent of mass m!)

h₂ = h₁ = 0.75 m above tabletop

Try changing the Pendulum Bob Mass ($m$) and re-running: notice that while $E_g$, $E_k$, and $E_T$ (in Joules) scale proportionally with mass, the speed at the bottom ($v_{\text{bottom}}$) and maximum height ($h_2$) remain unchanged because $m$ cancels out!
